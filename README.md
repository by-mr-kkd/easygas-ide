# EasyGAS IDE

แอปสำหรับสร้างเครื่องมือบน Google Apps Script ด้วย AI: พิมพ์บอกว่าอยากได้อะไร แล้ว AI จะเขียนโค้ดให้ พรีวิวได้ทันที จากนั้นกดเผยแพร่ขึ้นบัญชี Google ของคุณเอง หรือดึงสคริปต์ที่มีอยู่แล้วในบัญชีลงมาให้ AI วิเคราะห์และแก้ต่อ พร้อมประวัติย้อนคืนได้

ดาวน์โหลดและคู่มือ: <https://easygaside.tech>

แอปติดตั้งในเครื่องของคุณ ไม่มีเซิร์ฟเวอร์กลาง ใช้ AI กับบัญชี Google ของคุณเองทั้งหมด

Powered by **Mr.KKD**

## สิ่งที่ต้องมี

- Windows 10/11
- **AI อย่างใดอย่างหนึ่ง** เลือกได้ในหน้า ตั้งค่า
  - **API key** ของผู้ให้บริการที่คุณใช้ (Anthropic, OpenAI, Gemini, DeepSeek หรือ GLM) จ่ายตามการใช้งานจริง
  - **แพ็กเกจ Claude Pro/Max** ผ่านโปรแกรม [Claude Code](https://claude.com/claude-code) ที่ติดตั้งและล็อกอินไว้ในเครื่อง
  - **แพ็กเกจ ChatGPT** ผ่านโปรแกรม Codex ของ OpenAI ที่ติดตั้งและล็อกอินไว้ในเครื่อง
  - **แพ็กเกจ Muse Code** ของ Meta ที่ติดตั้งและล็อกอินไว้ในเครื่อง
  - ทุกแบบกดติดตั้งและล็อกอินได้จากหน้า ตั้งค่า ไม่ต้องมี Node.js และไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ หน้าตั้งค่าบอกให้ว่าล็อกอินแล้วหรือยัง และแถบล่างของโปรเจกต์แสดงโควตาที่เหลือของ Codex (ของ Claude เปิดได้ในหน้า ตั้งค่า)
- **บัญชี Google** ที่เปิด Apps Script API แล้ว (ทำครั้งเดียวที่ <https://script.google.com/home/usersettings>) ใช้ตอนเผยแพร่และตอนดึงสคริปต์เดิมเท่านั้น ยังไม่เชื่อมก็สร้างและแก้ได้ ในหน้า ตั้งค่า มีวิธีเชื่อมทีละขั้นพร้อมภาพ

## ข้อมูลของคุณอยู่ที่ไหน

ทุกอย่างอยู่ในเครื่องของคุณ ที่โฟลเดอร์ `%APPDATA%\EasyGAS IDE`

| ที่เก็บ | มีอะไร |
|---|---|
| `projects\<id>\src\` | โค้ดของแต่ละโปรเจกต์ เปิดแก้ด้วยโปรแกรมอื่นได้ |
| `projects\<id>\messages.jsonl` | ประวัติแชท |
| `projects\<id>\versions\` | เวอร์ชันย้อนหลัง เทียบและย้อนคืนได้จากปุ่ม "ประวัติ" |
| `projects\<id>\remote-baseline.json` | สคริปต์ที่ดึงมาจาก Google: สำเนา ณ ตอนดึง/ส่งล่าสุด ใช้ตรวจว่ามีใครแก้บน Google ก่อนส่งทับ |
| `settings.json` | AI ที่เลือก, API key และสไตล์เริ่มต้นของคุณ |
| `lessons.json` | บทเรียนของคุณ |
| `rulebook\` | ชุดกฎที่อัปเดตจาก GitHub (ถ้ามีรุ่นใหม่กว่าที่มากับแอป) |
| `clasp\` | การเชื่อมต่อบัญชี Google (ผ่าน clasp ของ Google) |
| `remote.json` | ใช้จากมือถือ: เปิด/ปิด, มือถือที่จับคู่ และ PIN (เก็บเป็นค่าแฮชเท่านั้น) |
| `tools\` | cloudflared ของ Cloudflare ที่ดาวน์โหลดตอนเปิดใช้จากนอกบ้านครั้งแรก (ตรวจ SHA-256 ก่อนใช้) |

- **API key:** ส่งตรงไปยังผู้ให้บริการ AI ที่คุณเลือกเท่านั้น
- **ใช้จากมือถือ (ปิดเป็นค่าเริ่มต้น):** เมื่อเปิด แอปรับคำขอจากมือถือที่จับคู่แล้วเท่านั้น แบบ "จากที่ไหนก็ได้" วิ่งผ่าน Cloudflare quick tunnel แบบ https ตรงมาที่เครื่องคุณ Pro ส่งแค่ลิงก์ tunnel ล่าสุดไปที่เซิร์ฟเวอร์ Pro เพื่อทำลิงก์ประจำเครื่อง ไม่ส่ง PIN หรือรหัสของมือถือ รายละเอียดที่ `docs/REMOTE-PLAN.md`
- **Claude Code / Codex / Muse Code:** EasyGAS ไม่เก็บข้อมูลล็อกอินของโปรแกรมเหล่านี้ ข้อยกเว้นเดียวคือสวิตช์ "แสดงโควตา Claude" ในหน้า ตั้งค่า (ปิดเป็นค่าเริ่มต้น) ซึ่งใช้การล็อกอินของ Claude Code ถาม Anthropic เรื่องโควตาเท่านั้น ไม่เก็บ ไม่ส่งที่อื่น

## ปรับให้เป็นแบบของคุณ

- **ตัวช่วยเริ่มโปรเจกต์:** โปรเจกต์ใหม่จะถามทีละเรื่อง (ใช้ทำอะไร, เก็บข้อมูลที่ไหน, ใครเข้าใช้ได้, ต้องการอะไรเพิ่ม, หน้าตา) กด "พิมพ์เอง" เพื่อข้ามได้
- **สไตล์:** เลือกกล่องแจ้งเตือน, CSS (เขียนเอง / Tailwind / Bootstrap), ไอคอน, ฟอนต์ไทย และเมนู ได้ในหน้า ตั้งค่า ตั้งต่างกันรายโปรเจกต์ได้ที่ปุ่ม "สไตล์" ในแชท หรือบอก AI ในแชทก็ได้
- **สิ่งที่เปลี่ยนไม่ได้:** กฎด้านความปลอดภัยและข้อจำกัดของ Google Apps Script เช่น การกันข้อมูลเขียนทับกัน
- **บทเรียน:** เมื่อ AI พลาดแล้วแก้ได้ มันจะเสนอบทเรียนให้คุณกด "เก็บไว้" ในแชท บทเรียนที่เก็บจะถูกใช้กับโปรเจกต์ต่อไป จัดการ เขียนเอง หรือแชร์ให้ชุดกฎกลางได้ในหน้า ตั้งค่า
- **ชุดกฎ:** แอปดาวน์โหลดชุดกฎรุ่นใหม่จาก GitHub วันละครั้ง ปิดได้ในหน้า ตั้งค่า แอปไม่ส่งข้อมูลหรือโค้ดของคุณออกไป และใช้ไฟล์ก็ต่อเมื่อลายเซ็นของผู้ดูแลถูกต้อง
- **ใช้จากมือถือ:** ตั้งค่า → ใช้จากมือถือ เปิดสวิตช์ แล้วสแกน QR ด้วยมือถือ สั่ง AI ดูพรีวิว และเผยแพร่ได้จากนอกบ้าน ตั้ง PIN และถอนมือถือได้จากคอมเท่านั้น ระหว่างเปิด คอมจะไม่เข้าโหมดพัก และปิดหน้าต่างแล้วแอปยังทำงานที่ไอคอนมุมขวาล่าง

## สำหรับนักพัฒนา

ต้องใช้ Node.js 22.18 ขึ้นไป

```bash
npm install
npm run dev        # http://127.0.0.1:3000
npm run desktop:build   # ตัวติดตั้ง Windows → dist/desktop/out (ดู docs/DESKTOP.md)
npm test           # unit tests
npm run typecheck
npm run build      # รวม check-trace: ห้ามมีไฟล์นอกโปรเจกต์หลุดเข้า bundle
```

ตัวแปร environment สำหรับพัฒนา:

| ตัวแปร | ใช้ทำอะไร |
|---|---|
| `EASYGAS_DATA_DIR` | ย้ายโฟลเดอร์ข้อมูล (ใช้ตอนทดสอบ จะได้ไม่ปนกับข้อมูลจริง) |
| `EASYGAS_CLASP_AUTH` | ชี้ไปที่ไฟล์ล็อกอิน clasp ที่มีอยู่แล้ว |
| `EASYGAS_CLAUDE_PATH` | ระบุตำแหน่ง `claude.exe` เอง |
| `EASYGAS_CODEX_PATH` | ระบุตำแหน่ง `codex.exe` เอง |
| `EASYGAS_RULEBOOK_URL` | ทดสอบชุดกฎจากที่อื่นก่อนปล่อยจริง (ยังตรวจลายเซ็นเหมือนเดิม) |
| `ANTHROPIC_API_KEY` และอื่น ๆ | คีย์สำรอง ถ้าไม่ได้ใส่ไว้ในหน้า ตั้งค่า |

### โครงสร้าง

- `lib/local/`: ที่เก็บข้อมูลแบบไฟล์ในเครื่อง พร้อมตัวกัน path ไม่ให้หลุดออกนอก `src/`
- `lib/engines/claude-cli.ts`: โหมดแพ็กเกจรายเดือน สั่ง `claude -p` ของผู้ใช้ในโฟลเดอร์โปรเจกต์
- `lib/engines/codex-cli.ts`: โหมด ChatGPT สั่ง `codex exec` ของผู้ใช้แบบไม่มีสิทธิ์อ่านเขียนไฟล์หรือรันคำสั่ง แอปส่งไฟล์ให้และบันทึกการแก้ไขเอง
- `lib/anthropic-agent.ts`, `lib/openai-agent.ts`: โหมด API key
- `lib/clasp.ts`, `lib/deploy.ts`: deploy ผ่าน clasp
- `lib/preferences.ts`: ตัวเลือกสไตล์ที่ผู้ใช้เปลี่ยนได้ และบล็อกคำสั่งที่ส่งให้ AI
- `lib/rulebook/`, `rulebook/`: ชุดกฎแบบการ์ด การเลือกการ์ดตามงาน และการอัปเดตแบบเซ็นลายเซ็น ดู [docs/RULEBOOK.md](docs/RULEBOOK.md)
- `lib/brief.ts`: คำตอบจากตัวช่วยเริ่มโปรเจกต์
- `lib/lessons.ts`, `lib/lessons-store.ts`: สมุดบทเรียนของเครื่อง
- `app/about/`, `lib/donate.ts`: หน้า เกี่ยวกับ และปุ่มสนับสนุนผู้พัฒนา (QR พร้อมเพย์สร้างในเครื่อง) ใส่เลขพร้อมเพย์ของผู้รับที่ `DONATION.promptPayId` ถ้าเว้นว่าง ปุ่มจะไม่แสดง
- `electron/main.js`, `scripts/build-desktop.mjs`: เปลือกเดสก์ท็อปและตัวสร้างตัวติดตั้ง
- `middleware.ts`: รับเฉพาะ `127.0.0.1` และกันคำขอข้ามเว็บ (DNS rebinding / CSRF)
- `docs/SPIKES.md`: ผลทดสอบและกับดักที่เจอ
