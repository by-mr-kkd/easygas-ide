# แอปเดสก์ท็อป (Windows)

เอกสารนี้สำหรับคนดูแล EasyGAS IDE: วิธีสร้างตัวติดตั้ง โครงสร้างของแอปที่ห่อแล้ว และสิ่งที่ยังไม่ได้ทำ

## สร้างตัวติดตั้ง

```bash
npm run desktop:build   # ได้ dist/desktop/out/EasyGAS-IDE-Setup-<เวอร์ชัน>.exe
npm run desktop:dir     # ได้เฉพาะแอปที่ยังไม่บีบอัด (dist/desktop/out/win-unpacked) เร็วกว่า ใช้ลองรัน
```

- เลขเวอร์ชันมาจาก `version` ใน `package.json` เพิ่มเลขก่อน build ทุกครั้งที่จะส่งให้ผู้ใช้
- ตอนพัฒนาไม่ต้องห่อ ใช้ `npm run dev` เหมือนเดิม
- ครั้งแรก electron-builder จะดาวน์โหลด Electron และ NSIS (ต้องต่ออินเทอร์เน็ต)
- ไอคอน `build/icon.ico` ประกอบเองใน `scripts/build-desktop.mjs` (256 พิกเซลย่อจากรูป 512): ถ้าปล่อยให้ electron-builder แปลงจาก PNG เอง มันใช้เครื่องมือ WebAssembly ที่ล้มเมื่อหน่วยความจำเหลือน้อย (`WebAssembly.Memory(): could not allocate memory`) ซึ่งน่าจะเป็นต้นเหตุที่ build ล้มเป็นครั้งคราวก่อนหน้านี้

## ข้างในแอป

| ส่วน | อยู่ที่ไหนหลังติดตั้ง | มาจาก |
|---|---|---|
| เปลือก Electron | `resources/app.asar` (มีแค่ `main.js` กับ `package.json`) | `electron/main.js` |
| เซิร์ฟเวอร์ของแอป | `resources/app/` | `.next/standalone` + `.next/static` + `public` |
| clasp | `resources/clasp/clasp.mjs` | clasp ของ Google รวมเป็นไฟล์เดียวด้วย esbuild |

`electron/main.js` ทำสี่อย่าง: เปิดเซิร์ฟเวอร์เป็นโปรเซสลูกบนพอร์ตว่างของ `127.0.0.1`, แสดงแอปในหน้าต่างเดียว, ส่งลิงก์ภายนอกไปเปิดในเบราว์เซอร์ของผู้ใช้ และปิดเซิร์ฟเวอร์พร้อมโปรเซสลูกทั้งหมดเมื่อปิดแอป

ที่เก็บข้อมูล:

- ข้อมูลของผู้ใช้อยู่ที่ `%APPDATA%\EasyGAS IDE` เหมือนตอนพัฒนา การถอนการติดตั้งไม่ลบโฟลเดอร์นี้
- ไฟล์ของ Electron เอง (cache และ `server.log`) อยู่ใน `%APPDATA%\EasyGAS IDE\electron`

## เหตุผลของการออกแบบ (อย่าแก้กลับ)

- **เซิร์ฟเวอร์กับ clasp ถูกคัดลอกด้วย `scripts/desktop-after-pack.cjs` ไม่ใช้ `extraResources`:** electron-builder ตัดโฟลเดอร์ `node_modules` และโฟลเดอร์ที่ขึ้นต้นด้วยจุด (`.next`) ออกจาก `extraResources` เงียบ ๆ แอปที่ได้จะเปิดไม่ขึ้น
- **`files` ใน `electron-builder.yml` ต้องมี `!**/node_modules/**`:** ไม่อย่างนั้นตัวห่อจะไล่ขึ้นไปเก็บ `node_modules` ของทั้ง repo (240 MB) ใส่ `app.asar`
- **clasp ต้องเป็นไฟล์เดียว:** clasp กับไลบรารีที่มันใช้มี 4,600 ไฟล์ หลังติดตั้งใหม่ Windows สแกนทุกไฟล์ในการใช้ครั้งแรก การตรวจบัญชี Google ครั้งแรกจึงเกิน 20 วินาทีและหมดเวลา และตัวติดตั้งใช้เวลา 107 วินาที พอรวมเป็นไฟล์เดียว ติดตั้งเหลือ 35 วินาที
- **`HOSTNAME=127.0.0.1`** ต้องส่งให้เซิร์ฟเวอร์เสมอ ไม่อย่างนั้น Next จะเปิดรับจากทั้งเครือข่าย
- **ห้ามมีตัวแปร `ELECTRON_RUN_AS_NODE` ตอนเปิดแอป:** ถ้ามี Electron จะทำตัวเป็น Node เปล่า ๆ แล้วปิดทันที ผู้ใช้ทั่วไปไม่มีตัวแปรนี้ แต่ terminal ของ VS Code มี

- **เซิร์ฟเวอร์เปิดผ่าน `desktop-entry.js`** (`electron/server-entry.js`): ตัวเปลือกถือ stdin ของเซิร์ฟเวอร์ไว้ ถ้าเปลือกถูกปิดแบบบังคับ เซิร์ฟเวอร์จะรู้และปิดตัวเองพร้อมโปรเซสลูก

## ทดสอบแล้ว (0.1.0, Windows 11)

- ติดตั้งแบบเงียบ เปิดแอป โหลดหน้าโปรเจกต์ ตั้งค่า และเกี่ยวกับ
- แอปที่ห่อแล้วตรวจบัญชี Google ผ่าน clasp ได้ และ AI (โหมด Claude Code) สร้างโปรเจกต์ได้
- clasp แบบไฟล์เดียว: ดูสถานะล็อกอิน, list deployments, pull และ push
- ปิดหน้าต่างแล้วไม่มีโปรเซสค้าง และพอร์ตถูกปล่อย
- ถอนการติดตั้ง: ไฟล์ ทางลัด และรายการในระบบหายหมด ข้อมูลผู้ใช้ไม่ถูกแตะ

ยังไม่ได้ทดสอบ: หน้าตาของตัวติดตั้งแบบกดทีละหน้า (รวมหน้ายอมรับ license), การ deploy จากแอปที่ติดตั้งแล้ว, และเครื่องที่ไม่ใช่ผู้ดูแลระบบ

## ยังไม่ได้ทำ

- **อัปเดตอัตโนมัติ:** ต้องมี repo บน GitHub ก่อน แล้วเพิ่ม `electron-updater` กับ `publish` ใน `electron-builder.yml`
- **เซ็นตัวติดตั้ง:** ตอนนี้ไม่ได้เซ็น Windows จะขึ้นคำเตือน SmartScreen ตอนติดตั้ง
- **เก็บ API key ด้วยระบบของ Windows** (Electron `safeStorage`) ตอนนี้ยังเก็บเป็นข้อความธรรมดาใน `settings.json`
- **macOS และ Linux**
- **ปิด Electron fuses ที่ไม่ใช้** (`NodeCliInspect`, `NodeOptions`) ส่วน `RunAsNode` ต้องเปิดไว้ เพราะเซิร์ฟเวอร์และ clasp รันด้วยวิธีนี้

## ข้อจำกัดด้านความปลอดภัยที่รู้อยู่

- เซิร์ฟเวอร์กับ clasp อยู่นอก `app.asar` โปรแกรมอื่นที่รันในบัญชีผู้ใช้เดียวกันจึงแก้ไฟล์พวกนี้ได้ เช่นเดียวกับแอปที่ติดตั้งแบบต่อผู้ใช้ทั่วไป ถ้าผู้ใช้เลือกติดตั้งในโฟลเดอร์ที่บัญชีอื่นเขียนได้ ความเสี่ยงจะกว้างขึ้น
- ไฟล์ที่ build แล้วมีพาธของเครื่องที่ build (`F:\SaaS\EasyGAS-IDE`) ติดไปด้วย ไม่มีชื่อผู้ใช้หรือคีย์
